Vamos **aumentar drasticamente** o leque de comandos para tornar o explorador de ficheiros uma **ferramenta de produtividade comparável a um ambiente Unix/Linux**, mas tudo dentro do teu ecossistema Java.

Abaixo está a lista **completa e expandida** de comandos, organizada por categorias funcionais. Incluo sintaxe, exemplos e onde encaixar na implementação.

---

## 📁 CATEGORIA 1 – MANIPULAÇÃO DE TEXTO E CONTEÚDO

### `grep` – Filtrar linhas com padrão
```
grep [-i] [-v] [-n] [-c] [-A n] [-B n] <padrão> <arquivo>
```
- `-i` ignore case
- `-v` inverter (mostrar linhas que **não** contêm)
- `-n` mostrar números de linha
- `-c` contar ocorrências
- `-A n` mostrar n linhas **após** a ocorrência
- `-B n` mostrar n linhas **antes** da ocorrência

**Exemplo:** `grep -i "erro" log.txt -A 2 -B 1`

---

### `sed` – Editor de fluxo (substituição, deleção, filtro)
```
sed '<expressão>' <arquivo> [-i]
```
**Expressões comuns:**
- `s/old/new/g` – substituir todas as ocorrências
- `/pattern/d` – eliminar linhas com `pattern`
- `10,20d` – eliminar linhas 10 a 20
- `s/^[0-9]//` – remover dígitos no início de cada linha
- `-n '10,20p'` – mostrar apenas linhas 10 a 20
- `-i` – editar in-place (modificar o ficheiro)

**Exemplo:** `sed 's/foo/bar/g' config.txt -i`

---

### `awk` – Processamento de dados estruturados
```
awk [-F delimitador] '<programa>' <arquivo>
```
**Programas úteis:**
- `{print $1, $3}` – imprimir colunas 1 e 3
- `{sum+=$1} END {print sum}` – somar coluna 1
- `{if($2>10) print}` – condição
- `{print toupper($0)}` – converter para maiúsculas

**Exemplo:** `awk -F',' '{print $2, $4}' data.csv`

---

### `replace` – Substituir texto simples (modo simples)
```
replace "antigo" "novo" <arquivo> [-i] [-n] [-g]
```
- `-i` editar in-place
- `-n` apenas mostrar (não alterar)
- `-g` substituir todas (padrão)

**Exemplo:** `replace "TODO" "DONE" notas.txt -i`

---

### `tr` – Traduzir ou eliminar caracteres
```
tr <conjunto1> <conjunto2> <arquivo>
```
**Exemplos:**
- `tr 'a-z' 'A-Z'` – maiúsculas
- `tr -d '0-9'` – eliminar dígitos
- `tr -s ' '` – comprimir espaços duplicados

**Exemplo:** `tr '[:upper:]' '[:lower:]' texto.txt`

---

### `col` – Extrair colunas (como cut)
```
col <arquivo> <colunas> [-d delimitador] [-t]
```
- `-d` delimitador (padrão: espaço)
- `-t` saída com TAB

**Exemplo:** `col data.csv 1,3,5 -d ','`

---

### `paste` – Concatenar ficheiros lado a lado
```
paste <arquivo1> <arquivo2> ... [-d delimitador]
```
**Exemplo:** `paste nomes.txt ids.txt -d '|'`

---

### `join` – Juntar ficheiros por campo comum
```
join [-t char] [-1 campo] [-2 campo] <arquivo1> <arquivo2>
```
**Exemplo:** `join -t ',' -1 1 -2 2 clientes.csv pedidos.csv`

---

### `split` – Dividir ficheiro em partes
```
split <arquivo> [-l linhas] [-b bytes] [prefixo]
```
**Exemplo:** `split log.txt -l 100 parte_`

---

### `tac` – Inverter a ordem das linhas
```
tac <arquivo>
```
(Sim, `cat` ao contrário)

**Exemplo:** `tac log.txt` (mostra da última linha para a primeira)

---

### `nl` – Numerar linhas
```
nl <arquivo> [-n estilo] [-w número]
```
- `-n` estilo: `ln` (à esquerda), `rn` (à direita), `rz` (zero-padded)
- `-w` largura

**Exemplo:** `nl relatorio.txt -n rz -w 3`

---

### `fold` – Quebrar linhas longas
```
fold <arquivo> [-w largura] [-s]
```
- `-s` quebrar em espaços (preservar palavras)

**Exemplo:** `fold mensagem.txt -w 80 -s`

---

### `expand` / `unexpand` – Converter tabs ↔ espaços
```
expand <arquivo> [-t N]   # tabs → espaços (N espaços por tab)
unexpand <arquivo> -a     # espaços → tabs
```
**Exemplo:** `expand codigo.java -t 4`

---

### `iconv` – Converter encoding
```
iconv <arquivo> [-f encoding] [-t encoding]
```
**Exemplo:** `iconv texto.txt -f ISO-8859-1 -t UTF-8`

---

### `dos2unix` / `unix2dos` – Converter quebras de linha
```
dos2unix <arquivo>   # CRLF → LF
unix2dos <arquivo>   # LF → CRLF
```

---

## 📁 CATEGORIA 2 – COMPARAÇÃO E DIFERENÇAS

### `diff` – Comparar dois ficheiros
```
diff <arquivo1> <arquivo2> [-u] [-i] [-w]
```
- `-u` saída unificada (contexto)
- `-i` ignorar maiúsculas/minúsculas
- `-w` ignorar espaços

**Exemplo:** `diff config_v1.xml config_v2.xml -u`

---

### `patch` – Aplicar um diff a um ficheiro
```
patch <arquivo> <diff_file> [-o output]
```
**Exemplo:** `patch programa.java alteracao.diff`

---

### `cmp` – Comparar byte a byte
```
cmp <arquivo1> <arquivo2>
```
Mostra o primeiro byte onde diferem.

---

### `md5sum` / `sha256sum` – Checksums
```
md5sum <arquivo>
sha256sum <arquivo>
```
**Exemplo:** `md5sum ficheiro.zip`

---

## 📁 CATEGORIA 3 – INFORMAÇÃO E ESTATÍSTICAS

### `wc` – Contagem de linhas, palavras, caracteres
```
wc <arquivo> [-l] [-w] [-c] [-m]
```
- `-l` linhas
- `-w` palavras
- `-c` bytes
- `-m` caracteres

**Exemplo:** `wc relatorio.txt -lw`

---

### `strings` – Extrair strings legíveis de binários
```
strings <arquivo> [-n len]
```
**Exemplo:** `strings programa.exe -n 10`

---

### `hexdump` – Visualização hexadecimal
```
hexdump <arquivo> [-C] [-n bytes]
```
- `-C` formato canónico (hex + ASCII)

**Exemplo:** `hexdump imagem.bin -C -n 256`

---

### `file` – Identificar tipo de ficheiro
```
file <arquivo>
```
**Exemplo:** `file programa.jar` → "Java archive data"

---

### `du` – Uso de disco
```
du <diretório> [-h] [-s] [--exclude=...]
```
- `-h` human-readable
- `-s` sumário

**Exemplo:** `du . -h --exclude=target`

---

### `df` – Espaço livre em disco
```
df [-h] [-t tipo]
```
**Exemplo:** `df -h` (mostra todos os sistemas de ficheiros)

---

## 📁 CATEGORIA 4 – OPERAÇÕES COM FICHEIROS (AVANÇADO)

### `find` – Pesquisa avançada
```
find <diretório> [-name pattern] [-type f/d] [-size +N] [-mtime +N] [-exec cmd]
```
**Exemplos:**
- `find . -name "*.txt" -type f`
- `find . -size +10M`
- `find . -mtime -7` (modificados na última semana)
- `find . -exec grep -l "TODO" {} \;`

---

### `xargs` – Executar comandos com argumentos
```
<comando> | xargs <cmd>
```
**Exemplo:** `find . -name "*.log" | xargs rm`

---

### `parallel` – Executar em paralelo
```
parallel <cmd> ::: <lista>
```
**Exemplo:** `parallel "gzip {}" ::: *.txt`

---

### `watch` – Repetir comando em tempo real
```
watch <comando> [-n segundos]
```
**Exemplo:** `watch "ls -l" -n 2`

---

### `time` – Medir tempo de execução
```
time <comando>
```
**Exemplo:** `time copy grande.dat backup/`

---

### `ln` – Criar links simbólicos / hard links
```
ln [-s] <origem> <destino>
```
- `-s` link simbólico (soft)

**Exemplo:** `ln -s /usr/bin/python python`

---

### `chmod` – Alterar permissões
```
chmod <modo> <arquivo>
```
**Exemplos:**
- `chmod +x script.sh`
- `chmod 755 programa`

---

### `chown` – Alterar dono/grupo
```
chown <user>[:grupo] <arquivo>
```
**Exemplo:** `chown joao:staff config.txt`

---

### `stat` – Estatísticas detalhadas do sistema de ficheiros
```
stat <arquivo>
```
Mostra inode, blocos, permissões numéricas, etc.

---

### `touch` – Já tens, mas pode atualizar timestamps
```
touch [-a] [-m] <arquivo>
```
- `-a` atualizar apenas acesso
- `-m` atualizar apenas modificação

---

- `-c` limpar histórico
- `-n N` mostrar últimas N

**Exemplo:** `history -n 20`

---

alias <nome>='<comando>'

## 📁 CATEGORIA 6 – COMPRESSÃO E ARQUIVOS

### `tar` – Arquivo .tar, .tar.gz, .tar.bz2
```
tar -cvf archive.tar <ficheiros>    # criar
tar -xvf archive.tar                 # extrair
tar -czvf archive.tar.gz <dir>       # comprimir com gzip
```
- `-c` criar
- `-x` extrair
- `-z` gzip
- `-j` bzip2
- `-v` verbose
- `-f` ficheiro

**Exemplo:** `tar -czvf backup.tar.gz dados/`

---

### `zip` / `unzip` – Ficheiros ZIP
```
zip -r archive.zip <dir>
unzip archive.zip -d destino/
```

---

### `gzip` / `gunzip` – Compressão simples
```
gzip ficheiro.txt    # ficheiro.txt.gz
gunzip ficheiro.txt.gz
```

---

### `bzip2` / `bunzip2` – Compressão mais eficiente
```
bzip2 ficheiro.txt
bunzip2 ficheiro.txt.bz2
```

---

### `7z` – 7-Zip (suporte a múltiplos formatos)
```
7z a archive.7z <ficheiros>
7z x archive.7z -o/pasta
```

## 📁 CATEGORIA 7 – CONVERSÃO DE FORMATOS

### `convert` – Conversão entre formatos estruturados
```
convert <input> <output> [--type formato]
```
**Exemplos:**
- `convert dados.csv dados.json`
- `convert config.xml config.yaml`
- `convert banco.db banco.json`

Suporte: CSV, JSON, XML, YAML, Properties, SQLite → JSON/CSV/XML.

---

### `yq` – Processamento de YAML/JSON (como jq para YAML)
```
yq '.servers[0].host' config.yml
```

---

### `jq` – Processamento de JSON (se disponível)

jq '.users[] | select(.active==true)' dados.json
```

---

### `xmlstarlet` – Manipulação de XML (se disponível)

xmlstarlet sel -t -v "/root/name" dados.xml
```

## 📁 CATEGORIA 8 – UTILITÁRIOS DE TEXTO AVANÇADOS

### `jump` – Navegação interativa dentro de ficheiro
```
view <arquivo>        # abre modo pager (less-like)
```
Dentro do modo:
- `:20` → saltar para linha 20
- `/palavra` → pesquisar
- `n` → próximo resultado
- `q` → sair

---

### `lines` – Seleção avançada
```
lines <arquivo> [intervalo] [opções]
```
**Intervalos:**
- `5` → linha 5
- `10-20` → linhas 10 a 20
- `:5` → 5 primeiras
- `-5` → 5 últimas
- `even` → linhas pares
- `odd` → linhas ímpares
- `10,20,30` → linhas específicas
- `pattern` → linhas que contêm `pattern`

**Exemplo:** `lines log.txt 100-200`
